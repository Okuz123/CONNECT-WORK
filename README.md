# CONNECT WORK

A multi-platform marketplace connecting **skilled workers** with **people who need them**.
Includes customer, owner, worker, and admin panels.

## Structure
- `apps/android/` — Native Android app (Kotlin + Jetpack Compose)
- `apps/web/` — Web app + admin dashboard (React + Vite)
- `apps/mobile-pwa/` — Installable Progressive Web App (works on iPhone)
- `server/` — Node.js + Express + Firebase backend
- `shared/` — Shared TypeScript types, constants, validators
- `design/` — Wireframes, brand assets
- `docs/` — Documentation
- `scripts/` — Dev / deploy scripts
