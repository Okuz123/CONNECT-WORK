# Roles & Permissions

| Role | Capabilities |
|------|--------------|
| **Customer** | Post jobs, browse workers, hire, pay, review |
| **Worker** | Create profile, list skills, apply to jobs, get hired |
| **Owner** | Manage business, staff, jobs, subscriptions |
| **Admin** | Approve users, moderate content, view analytics, configure platform |

## Role assignment
- Default role on signup: `customer`
- Upgrade to `worker` via profile setup
- Upgrade to `owner` via business registration (admin-approved)
- `admin` set manually in Firestore
